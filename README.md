# Redis wrapper
- Great cache invalidation feature with basic knowledge graph
- Simple channel behaviour for different class types
- Entity based usage
- Hazelcast style usage
- Auto json values for entities
- Handled duplicated keys, fields ( hash ) and members ( set )
- Extended defaults & configuration to easy use
- And more ...
